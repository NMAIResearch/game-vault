# 🌌 Game Vault

**Games made with AI, playable in your browser.**

A community home for games made with AI, built by describing what you want and shaping it prompt by prompt. Every game plays right in your browser: no installs, no accounts, no tracking. From one-prompt jam toys to games iterated on for months, both belong here.

🎮 **Play:** every game in the vault runs right in your browser.
📤 **Share:** built something with Claude (or another model)? Submit it with a game submission issue on GitHub, or send a pull request.
💬 **Rate and discuss:** each game has its own discussion thread for reactions, ratings, and feedback to the creator.

---

## 🕹️ Play the games

Visit the vault at [nmairesearch.com/game-vault](https://nmairesearch.com/game-vault/): **the catalogue lists every game**; click a card to play. Games live in this repo under [`/games/`](games/), one folder each. Hosted by [NMAI Research](https://nmairesearch.com/).

## 📤 Submit your game

Two ways to be in the vault:

### Open games (the default)
Your game's source lives in this repo, free for anyone to play and learn from.

1. Your game should be a **self-contained browser game**: ideally a single `index.html` (inline JS/CSS), or a small folder with no build step and no external network calls.
2. **Open a [game submission issue](../../issues/new/choose)** with your game attached or linked, or send a pull request adding `games/<your-game-name>/index.html`.
3. Tell us: the game's name, a one-line description of its vibe, and which AI helped you build it.
4. The curator plays everything before it's merged. If it runs and it's yours, it's in.

### Creator listings (paid games)
Built something bigger you want to charge for? Submit a **playable demo** for the vault plus a link to the full version on [itch.io](https://itch.io) (or your own page). The vault is your discovery layer; payment happens entirely on your side, and we never touch the money.

**Submission rules (both tiers):**
- ✅ All assets (art, music, code) are yours, AI-generated by you, or properly licensed; you confirm this on submission.
- ✅ Browser-playable, no installs, no accounts, no tracking.
- ❌ No malware, no crypto-miners, no data collection. Submissions are reviewed before merge.

## 🧰 Run locally

```bash
git clone https://github.com/NMAIResearch/game-vault.git
cd game-vault
```
Serve the folder with any static web server, for example `python3 -m http.server`, then open the address it prints. Browsers may refuse to load the game list when `index.html` is opened straight from disk. No build step.
